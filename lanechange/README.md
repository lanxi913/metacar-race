- 200 s 内从起点开到终点，超时计 0
- **终点与起点不在同一条车道**，必须真的变道；到同车道终点不算完成

## 3. 关键发现：场景给的 route 不能用

实测这条 route 是一条**恒定 94.6° 的斜直线**（从 `(-2,-2)` 到 `(-6,-51.8)`），
它有两个问题：

1. **不平行车道** —— 跟着它跑，车到终点永远是斜的（实测 yaw=94.6°）
2. **离第一个障碍物只有 1.10 m**，车半宽 1.09 m，等于贴着过

所以必须自己造一条真正的变道轨迹。

---

## 4. 做法

```
读车道 -> 自建 "本车道直行 + S 弯 + 目标车道直行" -> Stanley 反馈 -> 自标定恒定油门
```

### 4.1 参考路径（`LaneChangePath`）

- 本车道中心线：直行到起点下方 `s_start_offset = 2 m`
- **余弦 S 弯**：横向从本车道中心过渡到目标车道中心
  - S 弯长度 `L = max(12, 5.5 × 横移量)` —— 由横移量推出来，不写死
  - 本题横移 3.74 m → L = 20.57 m
- 目标车道中心线：直行到终点

余弦 S 的形状保证**进入和退出时航向都是 90°**，这正是"先甩头再回正"的几何来源。

### 4.2 横向：Stanley 控制

```python
corr = degrees(atan2(k_cross * e_ct, max(|v|, 0.8)))
desired_yaw = yaw_ref + corr
steer = k_heading * wrap(desired_yaw - yaw)
```

- `e_ct` 是车到参考线的横向偏差（正 = 在右侧）
- 车在右侧 → 期望航向加大 → 往左打；过了参考线 → 自动反向 → **负反馈收敛**
- 实测终点：`e = 0.00 m`，`yaw = 90.0°`

### 4.3 纵向：自标定恒定油门

复用 `speed/main.py` 的 `AdaptiveCruise`：油门慢爬 → 检测车速平台 → 锁死，全程开环。

> 为什么不用"速度低了给油、高了刹车"的 bang-bang？
> 实测那样加速度抖动，`|a| ≤ 5` 的 10 分直接丢：同一套横向控制下，
> bang-bang 只有 **100 分**，换成标定后恒定油门就是 **110 分**。

## 6. 两个必须记住的坑

### 6.1 转向公式写错，只在 dx≈0 时蒙对

```python
desired_yaw = math.degrees(math.atan2(-(ty - y), -(tx - x)))   # 错
desired_yaw = -math.degrees(math.atan2(ty - y, tx - x))        # 对
```

| 目标 | 正确 | 错误公式 |
|---|---|---|
| 正前方 | 90° | 90°（巧合） |
| 左前方 | 92.1° | 87.9°（反向！） |

直行/限速题 dx≈0 所以没暴露；变道一上来就往右打方向、直接跑出车道。

### 6.2 导入顺序

脚本里 `sys.path.insert` 必须写在 `from speed.main import ...` **之前**，
否则当脚本以 `python lanechange\main.py` 运行时（`sys.path[0]` 是 lanechange 目录）
会 `ModuleNotFoundError: No module named 'speed'`。
