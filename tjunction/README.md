## 3. 关键认知：加速度是矢量

评分里的「加速度绝对值」不能只看纵向加速——过弯时**向心加速度** `a_lat = v²/R` 才是大头：

| 速度 | 拐角 R=1.85 m 时的 a_lat |
|---|---|
| 4.78 m/s（1 挡平台） | **12.3 m/s²** ❌ |
| 2.72 m/s | **4.0 m/s²** ✅ 刚好到预算 |

所以 `v = √(a_lat_budget × R)` 就是弯道限速的物理依据，不用调参。

## 4. 最终方案

```
读 route（不平滑） -> 求曲率 R(s) -> v_cap = √(4.0·R) -> 前视 20 m 取最小
                    -> PI 纵向（连续油门）-> 油门输出上限 0.40
                    -> 纯跟踪横向（车身坐标系）
```

### 4.1 不平滑路径（这条最反直觉）

早期版本为了"让弯走缓"对路线做滑动平均，结果**把 90° 弯走成大圆弧，直接压线扣 20**（实测 180 分）。

正确做法：**路径保持原样**（不压线），用曲率算子抑制航点噪声；弯道靠**减速**通过。

### 4.2 油门输出上限 0.40 —— 这才是拿到 +10 的关键

实测：只要触发**升挡**，`car.speed` 会在换挡瞬间跳变 1~2 m/s，平台就会判 `|a|` 超限
（诊断里出现过"油门为 0 却 +19 m/s²"的帧）。而升挡需要油门给到 1.0。

所以把**油门输出封顶在 0.40**，车自然稳定在 1 挡最高速 4.78 m/s，全程不换挡：

```
[9.5s] v=4.78  thr=0.40  a_lat=0.04
[10.0s] v=4.78  thr=0.40  a_lat=0.04
```

峰值 17.44 km/h，很平稳。

### 4.3 PI 纵向（连续量，不脉冲）

早期用 PWM 脉冲维持低速，视觉上一顿一顿、加速度也断断续续。改成 PI：

```python
err = v_cmd - v
pi_integ += err * dt                     # 限幅 -3 / +24
u = 0.10 * err + 0.05 * pi_integ
thr = min(0.40, u) if u >= 0 else 0
brk = min(1.0, -u * 1.6) if u < 0 else 0
```

油门是连续变化的，没有开关震荡。
