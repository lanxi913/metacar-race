代码里仍保留让行判据（前方 15 m / 横向 2.8 m），换相位或换场景时自动生效。

## 3. 控制律

```
横向  Follower：车身坐标系纯跟踪（同 leftturn / crossroad）+ 曲率限速 v=sqrt(a_lat*R)
纵向  Longi：加速度空间 PI（同 hillstop），油门 = a_cmd/150，刹车 = -a_cmd/32
起点  起步助力 LAUNCH_THR=0.15，让离合 0.2 s 内咬合（避开平台忽略窗口）
终点  沿终点方向越过 2 m 再刹停
```

### 3.1 看灯：能"配速"就不停车

只要场景里有红绿灯就必须看灯（playbook 铁律 17）。本进口的灯按几何自动认：

```python
along = ddx*heading_x + ddy*heading_y > 0        # 在车前方
right = -(ddx*left_x + ddy*left_y)               # 横向偏右
# 0.8 m < right < 12 m 里取 |right| 最小那盏；找不到退回 |right|<9 最近的
```

认到灯后按剩余时间决策：

| 条件 | 动作 |
|---|---|
| 绿灯 且 `t_min ≤ remain − SIGNAL_GUARD` | 巡航 `V_MAX` |
| 绿灯 但来不及 | 停线前 |
| 红灯/黄灯，且 `solve_speed(d_head, v, remain+0.8) ≥ 2.2 m/s` | **整段恒速配速**（不停车） |
| 红灯/黄灯，配速也来不及 | 匀减速剖面停在距线 2.5 m，等绿灯 |

`travel_time()` 用加速度受限的时间积分、"整段恒速"用二分反解 `solve_speed()`，
`hold_ff()` 给前馈减速度（并绕开 `Longi` 的积分——否则积分会顶住减速，实测 d_head
从 8 m 掉到 3 m 本该降到 1.9 m/s 却被顶成 4.06 m/s，随后 v_cmd 断崖、刹车一拍到底）。

两个现场坑：

1. **不能缓存 `TrafficLightInfo` 对象**：SDK 消息里的对象是快照，存下来字段永远不刷新
   （日志里 `直行=GREEN(4.6s) 右转=RED(4.6s)` 无限重复，车卡在路口等到 182 s）。
   每帧按 `id` 重新查。
2. **停止线只认一次，过线即永久停用**：否则右转完成后会把横向道路的出口停止线当成
   自己的（实测 x=−20 那条线 + 灯 2），把车限成 1.03 m/s 爬行 46 s 才到终点。

### 3.2 停车兜底（只在快红灯太长时用）

`cap = sqrt(2 × STOP_A_PROFILE × max(d_head − STOP_GAP, 0))`，`STOP_A_PROFILE=1.5`
（比实际可执行的 1.8~1.9 留 0.3 余量，否则剖面跟不上、冲过停点）。

实测停车点：y_center=24.438 → **车头距停止线 2.438 m**（规则允许 0~3 m ✓），
减速段刹车恒定 0.048~0.056（≈1.5 m/s²），静止期 v≈±0.02、brk 0.031。

## 5. 关键结论

1. **能不停就别停**：真停住再起步时，离合器咬合那两帧（v 0.015→0.519→1.03，
   15.1/15.3 m/s²）落在行程中段、不享受"起步 0.5 s"的豁免，+10 必丢（21:23/21:24 → 200）。
2. **软抬离合只能改善平顺、救不回加分**：`SOFT_LAUNCH_THR=0.05` 把再起步尖峰从
   15.3 压到 **6.03 m/s²**（21:26），体感明显好，但仍 > 5 → 还是 200。平台的门槛是硬 5。
3. **本场相位固定，配速永远来得及**：右转灯 t=0 红 4.9 s、t=5 转绿，`solve_speed`
   给一个 3.1~3.6 m/s 的恒速，车在 t≈6 以 4.19 m/s 绿灯压线，一次都不停 → 210。
4. **别为红绿灯磨蹭**（用户明确要求"流畅、一行到底"）：爬行/等待能拿分但体验差，
   还会额外制造加减速尖峰；"整段恒速配速"既守规则又不顿挫。

## 6. 复现

```powershell
cd metacar-race
.\.venv\Scripts\python.exe pedright\main.py --csv logs\ped.csv        # 正常跑
.\.venv\Scripts\python.exe pedright\main.py --hold-red 9 --csv logs\ped_stop.csv
                                                                      # 实跑"红灯停 0~3 m"分支
.\.venv\Scripts\python.exe pedright\main.py --no-light               # 仅调试：忽略灯
```

`--hold-red N` 是调试开关：开局前 N 秒把灯一律当红灯，用来实跑停车分支。

## 7. 未覆盖 / 已知限制

- 本场行人永不进 ego 车道，**让行判据没有在真实通行冲突下验证过**；
- 真红灯必须停车时只能拿 200（丢 +10），要保住需要在停车时做"刹车预载 + 极慢抬"
  把咬合压到 5 以内，本轮没做；
- 灯相位、`stop_line` 都从 SDK 读，但"哪盏灯是本进口的"用的是几何启发式
  （右偏 0.8~12 m），多车道/歪斜路口需要再放宽或改成按 `road_id` 关联。
