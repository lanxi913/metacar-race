## 3. 做法

```
读 route -> 滑动平均平滑 -> Stanley 跟线 -> 自标定恒定油门 -> 到终点滚过线再停
```

| 参数 | 来源 |
|---|---|
| 路线 | `SceneStaticData.route` |
| 平滑窗口 | 9 点滑动平均（k=4） |
| 横向控制 | Stanley（航向误差 + 横向偏差） |
| 巡航油门 | 在线自标定（0.77 → 17.2 km/h） |
| 结束条件 | 距最后一个路线点 < 1.2 m 后低速滚 3 s，再刹停等场景结束 |

---

## 4. 三个必须记住的坑

### 4.1 路线有急拐，不平滑就压线（-20）

原始路线在环岛进出口有 **R = 3.5 m** 的航点急拐，比车的最小转弯半径 3.8 m 还小。
直接跟会切角，横向偏差达 **2.40 m**（车道余量只有 ±0.78 m），压一次线扣 20 分 → 90 分。

**9 点滑动平均后**，同样车速下横向偏差降到 **1.10 m**，不再压线 → 110 分。

### 4.2 到终点别急着断开连接，否则平台不记分

实测：车到终点后脚本立刻退出 → 平台**完全没有记录**（连 0 分都没有）。

原因：平台要等场景进程把结果上传完，才生成记录。
`tools/auto_scene.ps1` 现在会在 python 退出后**等 12 秒**再结束 SmartCar，记录才稳定出现。

### 4.3 横向偏差符号（cross 方向）

```python
e_ct = cross      # 正确：cross>0 = 车在路径左侧，corr>0 -> 右打轮回正
e_ct = -cross     # 错误：双重反号 -> 正反馈 -> 车越偏越远（实测跑飞 76 m）
```
