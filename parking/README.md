## 1. 目标与规则

- 基础分 200，`|a| ≤ 5 m/s²` 另有 +10
- 200 s 内完成，超时计 0
- 压线 −20，碰车 −5×v

### 转向标定结果（`../steer_probe.py`）

| 动作 | steering | Δyaw（4 s） |
|---|---|---|
| 前进 | +0.5 | **+38.2°** |
| 倒车 | +0.5 | **−33.8°** |
| 倒车 | −0.5 | **+33.5°** |

结论：`yaw` 顺时针为正；前进时正舵使 yaw 增大，倒车时相反，且线性度很好。

## 4. 已知的关键坑

1. **油门近似开关式**：给 `0.05` 也会一路加速到 4.78 m/s（17.2 km/h 低挡位平台）。
   低速蠕行只能靠 PWM 脉冲，单帧约 +0.1 m/s。
2. **挡位切换有冲击**：PARKING ↔ DRIVE/REVERSE 来回切会触发弹射，
   必须"停稳再换挡"。
3. **路径方向不能逐帧取**：相邻点的 `d` 会抖，按帧切挡会导致控制器一直踩死刹车，
   车原地不动（已在 `controller.py` 用"方向段锁存"修掉）。
4. **几何模型偏差（未解决）**：`PoseGnss` 是车辆中心，而两弧公式按后轴推导，
   半车长 2.4 m 的偏移会让横向位移算少一半 —— 这是落位差 2.3 m 的主因。

## 5. 两种实现

| 文件 | 思路 | 结果 |
|---|---|---|
| `planner.py` + `controller.py` | Hybrid A* 规划 + 纯跟踪（`--mode astar`） | 能进车位，姿态偏 20~30° |
| `two_arc.py` | 前进到位 → 倒车正舵转 φ → 倒车反舵回正（`--mode arc`，默认） | 动作链跑通，落位差 2.3 m |

用法：

```powershell
.venv\Scripts\python.exe -u parking\main.py --mode arc
# 客户端点「启动场景」（平行车道泊车）
```

## 6. 下一步

1. 把中心偏移补进几何：`d = 2·R_center·(1−cos φ)`，`R_center = √(R_rear² + 2.4²)`
2. `arc2` 超时从 30 s 放宽（实测 30 s 只转过 33°，而需要 56°）
3. 加到位判定：位置误差 < 0.3 m 且 yaw 在 90±3° 才收工
4. 若仍不稳，考虑"倒车弧 + 三段微调"（前进纠正、倒车纠正各一次）
