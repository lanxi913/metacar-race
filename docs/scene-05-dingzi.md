## 二、场景几何

```
route 54 点，总长 53.0 m，终点 (27.9,-5.99)
自车起点 (5.80,-37.00) yaw=270（沿 +Y 北上）
14 条 road：主路 x≈154~158（双车道）、横向路 y≈3.75
T 型路口在路线中段，需左转进入横向路
```

## 三、关键结论

1. **路口场景不能套用"换道避让"**：路线本身已经包含了合并/转弯，额外的横向偏移会压线（−20）。
   通用做法：**参考路径已经绕开障碍时，不再叠加避让偏移**；只有在"路线是直线且正前方有静止车"时才需要换道。
2. 200 分档场景实测两次（本场景、上下坡驻车）都是正好 200.00，
   而 100 分档场景（超车/辅路）都是 110.00 —— **+10 加速度分只出现在 100 分档**，
   推测平台对 200 分档不叠加该奖励分。
