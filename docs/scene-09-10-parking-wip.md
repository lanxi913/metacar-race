## 七、第 18~21 轮结论（2026-10-24 12:30）

### 重要发现：这是"斜列式车位"，应车头驶入

第 21 轮截图确认（客户端场景卡片示意图 + 实测几何）：

```
车位 (-8.48,-2.04) ori=21.3°；两侧车 x 相同（-8.48）、y 不同（0.56 / -4.61）
→ 车位沿 Y 轴排成一列，但每辆车自身转了 21.3°
→ 车位与行驶方向（90°）夹角约 69°，是标准"斜列式停车位"
```

斜列式车位（60°~75°）的正确动作是**车头驶入**（不是倒车入库）：

| 环节 | 状态 |
|---|---|
| 车位/入场点解算（由 ori_z 与尺寸推导） | ✅ |
| 接近段外让 1.6 m 绕开斜停车的车角 | ✅ |
| 倒车打舵对齐 | ❌ 一挂 R 挡打舵立刻 v=0 |
| 车头驶入（纯跟踪瞄准车位中心） | ❌ 前视距离过长，切角切入时蹭到前车 |
