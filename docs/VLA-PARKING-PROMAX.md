## 四、识别层（`tools/vla_score_run_promax.py`）

- **两线程分离**：控制线程只把帧 memcpy 进共享内存；OCR 在子进程里跑（`RapidOCR(intra_op_num_threads=1)`），
  结果走队列；**控制线程从不做 OCR/编码，识别线程从不发指令**。
- 车框：颜色分割 `vla2.vision.detect_cars`（默认）；`--yolo 1` 才换 YOLO（conf .15 / iou .60 / imgsz 512）。
- 读号：RapidOCR **整帧直读**（不裁 ROI —— 裁了 660~806 ms vs 整帧 282~308 ms）。
- 归一化：`D/O→0`、`8→6`，只接受 `B-01~B-06`（编号每局重排，这条挡掉 `B-08`/`B-D2` 之类误读）。
- 区域：`--region-only 1` 用反投影世界点判是否在禁停区内（`inside()`，1.5 m 容忍带）。
- 交卷：`laps_done >= laps or now > seconds` → `票数 ≥ --min-votes 且 最高分 ≥ --min-score` → 按「票数↓、最高分↓」取 `--top-n 4` → `VLAExtensionOutput(parking_result=...)` **只交一次**。

## 五、为什么「报 3 个」而不是 4 个

- 第 4 辆车在这条贴边线上只有很短一段能看到车门白字，且常被前车挡；实测**永远只有 1~2 票**。
- `--min-votes 2` 就是那个开关：2 票才交 ⇒ 稳拿 857；降到 1 票去赌，赌对 1000、赌错 500~600（2026-10-28 实测 850 / 707 / 600 / 516 全出现过）。

## 六、被实验否掉的做法（别再试）

| 做法 | 结果 |
| --- | --- |
| 内环扫掠（inset 12 m 穿车阵补票） | 60 s 撞车、卡死 46 s → 707.14 |
| 出弯加深 0.2 m（bump） | 用户否决（「歪主意」），且只堆出 1~2 票 |
| 1.5 m 死区弱回打 / 直道零航向 | 稳态偏差翻倍，真车冲出禁停区（东沿 x=49.0） |
| 第一圈记忆表辅助第二圈 | 用户否决（「换一个思路」） |
| 裁框 OCR / `use_det=False` | 裁框带检测慢 2~4 倍且无增益；只识别 → 垃圾输出 |
| 弯里减速读号（`--read-speed`） | NW 角犁出参考线、未交卷 |
| 8 m 内整体减速 | 两圈超 120 s 时限 |
| 直道 2.80 + `--dup 2` + `--every 0.10` | 拿到过 1000，但本质是赌第 4 辆的 2 票，不可控 |
