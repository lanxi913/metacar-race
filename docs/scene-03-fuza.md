## 三、无经验参数的做法

| 环节 | 依据 |
|---|---|
| 参考路径 | `static.route` |
| 车道合法性 | `roads[].lanes[].path_points` 投影，只允许换到**真实存在的车道中心线** |
| 走廊判定 | `\|横向偏差 − 当前偏移\| < 车道宽/2 + 车半宽`（相对当前所在车道） |
| 换道滞回 | 决定后保持，连续 0.8 s 无阻挡才回原车道；本车道被堵（<25 m）可随时重选 |
| 速度上限 | `min(V_RULE, √(A_LAT/κ), v_req×1.35)`，其中 `v_req = 剩余距离/剩余时间` |
| 前车净距 | 安全距离 = 车长 4 m + 2 m，`v ≤ √(2·A_LONG·(gap−safe))` |
| 刹车限幅 | `0.35`（实测 1.0 ≈ 18 m/s²、0.35 ≈ 5 m/s²） |
| 起步 | 1 s 内油门从 0 爬升，抑制第一帧速度跳变 |

## 四、三处关键修复（都有遥测支撑）

| 问题 | 遥测证据 | 修复后 |
|---|---|---|
| 超速 | `vmax = 17.74 m/s = 63.9 km/h > 60` → 扣 10 | `vmax = 11.4 m/s` |
| 收尾急刹 | 终点前 10 m/s 一脚刹停，`\|a\| = 18.6` | 刹车限幅 0.35 → `\|a\| ≈ 13.8` |
| 起步跳变 | 第一帧 0→1.4 m/s，`\|a\| = 13.5` | 油门爬升 → 峰值前移到中段 |

## 五、为什么拿不到 +10 加速度奖励分（结论）

遥测逐跑统计（0.1 s 窗口）：

```
慢速版（vmax 5.35 m/s）  → 用时 31.5 s > 30 s → 超时判 0
快速版（vmax 10.85 m/s） → 用时 30.3 s → 200 分，但 max|a| = 13.8
```

**两个约束互斥**：

- 路线 146.9 m、时限 30 s → 平均必须 ≥4.9 m/s；
- 这台车模型的低速平台是 **4.78 m/s**（油门 ~0.1），不加油门就卡在平台，30.6 s 跑不完；
- 一旦加油门越过平台，仿真会**直接跳到 13+ m/s**，加速度尖峰 13~18 m/s²，`|a|≤5` 必然被破。

因此本场景在「30 s 内完成」与「|a|≤5」之间只能二选一，选前者得到 **200**（比 +10 更值）。
