## 二、两个通用改进（都不写死坐标）

### 1. 前车跟随（替代"终点前硬减速"）

```python
# 本车道前方 15 m 内有车，就按净距限速
gap = 障碍物弧长 - 自车弧长 - 障碍物半长 - 2 m
v_des = min(v_des, 0.45 * (gap - 3))
```

这样不管终点前停的是车还是别的，都会自动减速，而不是靠"到某米数就刹"这种经验值。

### 2. 破静摩擦

满舵（±0.8）+ 低速时车轮会顶死，车直接不动（实测卡了 60 s）。
判据：**想走（v_des > 0）但 |v| < 0.12 持续 0.8 s** → 给连续满油门 0.010 破开。
