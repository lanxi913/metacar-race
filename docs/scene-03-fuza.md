## 三、无经验参数的做法

| 环节 | 依据 |
|---|---|
| 参考路径 | `static.route` |
| 车道合法性 | `roads[].lanes[].path_points` 投影，只换到真实存在的车道 |
| 走廊判定 | `\|横向偏差 − 当前偏移\| < 车道宽/2 + 车半宽` |
| 换道滞回 | 决定后保持，连续 0.8 s 无阻挡才回原车道；本车道被堵（<25 m）可随时重选 |
| 速度上限 | `min(V_RULE, √(A_LAT/κ), v_req×1.15)`，`v_req = 剩余距离/剩余时间` |
| 前车净距 | 安全距离 = 车长 4 m + 2 m |
| 油门上限 | `THR_CAP = 0.105`（台阶标定：0.18 仍是 4.78 m/s，0.22 起跳挡/抖动） |
| 油门斜率 | **变道中 0.0008/帧，其余 0.0015/帧**（仿真对油门台阶有阶跃响应） |
| 刹车 | **巡航段 0.03、最后 10 m 0.08**（标定：0.10 ≈ 3 m/s²） |
| 加速度闭环 | 实测 `a_lp > 4` 缓慢收油（每次 −0.004，不归零，避免顿挫） |

## 四、拿到 210 的关键：中途刹车量必须比收尾还小

`tools/probe_brake_map.py` 实测：刹车 0.10 → 约 3 m/s²（4.65→0 用 1.6 s）。

但**超车时那一下刹车**（`brk = min(BRAKE_MAX, -err/1.2)`，BRAKE_MAX 取 0.08~0.20）
实际给出了 8~13 m/s² 的瞬时减速 —— 平台记「加速超标」，+10 拿不到。

改成**分段刹车上限**后一次通过：

```python
brk_cap = 0.08 if rem < 10.0 else 0.03   # 巡航/超车段 0.03，最后 10 m 才 0.08
brk_t = min(brk_cap, (-err) / 1.2)
```

## 七、排查过程中的关键结论（供其他场景参考）

1. **平台判加速度用比 0.1 s 更细的口径**：0.1 s 窗口 4.7 时仍被判超标，而中途把刹车压到 0.03 后事件消失；
2. **起步的仿真硬跳（约 1.2 m/s，单帧 12~14 m/s²）平台不判**——所有事件都出现在中途刹车或终点；
3. **终点强制停车**（4.7 → 0 瞬间）在柔和刹车版本里不再出现，说明车是被"中途刹车"害的，不是终点。
