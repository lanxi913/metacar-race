## 2. 四条成功要素（不得改动）

1. **两段真并行**：A 泊位段 = Car_D + Car_A 同时出发；B 泊位段 = Car_B + Car_A 同时出发（`drive_multi`，四车一次下发控制）。协同让两车观测天然落在同一 30 s 窗内。
2. **过闸不绕行**：获准后沿自然车道（x≈730.9 → 728.8）北上，11 s 内 release 成功。
3. **过闸速度 2.5~2.7 m/s**（不是 1.2 m/s）。
4. **全程不倒车**：A 交完直接前出、16 wp 去 B。

## 4. 只叠加的安全层（不改任何路径）

- `V_SAFE = 4.90`：超速 20.5 km/h = 5.69 m/s，留 0.8 m/s 余量。
- 拒绝 REVERSE 档：收到倒车即在下一帧改为 P 档 + 刹车（避免 −50 超速与 −100 碰撞）。
- 车距保护：他车 < 6.0 m → `brake ≥ 0.6`；< 4.0 m → `throttle=0, brake=1.0`。
- 斜率限幅：油门 ≤0.55/s、刹车 ≤0.90/s（消 −50 急加急减）。
- 禁用“卡死踢油门”：改为原地等待 + 记事件。
