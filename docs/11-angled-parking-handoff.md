## 二、用户明确的三条硬要求

1. **路径必须在路面上**，不许压路缘
   → 用 `static.route`（车道中心线）当骨架，路径点约束在「中心线 ± 半车道宽 − 车宽/2」走廊内
2. **前方有车要避让**
   → 按矩形包络判碰，不是按中心点：障碍矩形 = `len/2+0.3` × `wid/2+0.3`
3. **规划要考虑车体积**
   → 自车按 **4.0 × 1.8 m** 算，检查车体四角而不是车心；与障碍保持 ≥ 0.3 m 间隙

## 三、加速度约束（拿奖励分的前提）

- 仿真右上角出现 `[加速度限制] 加速度高于/低于允许上限` → 110/210 的奖励分（+10）立即失效
- **不要踩急刹**：减速度超限同样扣分
- 已验证的做法：只用油门开关调速（`0.10` / `0.0`），目标速度 0.5 m/s 左右
- 换挡前必须**滑行到 |v| < 0.08** 再换，否则换挡瞬间加速度爆表

## 四、已验证的坐标与符号约定（照抄，不要重新推）

```python
yaw = math.radians(-pose.ori_z)          # 场景 yaw 顺时针为正 → 数学航向取负
lx =  dx*math.cos(yaw) + dy*math.sin(yaw)
ly = -dx*math.sin(yaw) + dy*math.cos(yaw)
delta = math.atan2(2.0*ly, d)            # 纯跟踪
steer = -delta / 0.6                     # ← 这个负号是实测验证过的（track_bonus 拿过 110）
```

- **前进**方向：上面这套可直接用
- **倒车**方向：转向符号未标定，需先做一次标定（见下）

## 六、下一轮建议顺序（一步一验，一轮只跑一次）

1. **标定倒车转向**：倒挡固定 steer=+0.3 跑 2 s，看 yaw 变化；再 -0.3 跑 2 s。确定符号与增益
2. **只跑前进段**：沿 `static.route` 中心线换到左车道、开到 staging 点，验证不压路缘、不碰车
3. **加倒车段**：从 staging 倒进车位，逐帧打印 `pos / yaw / 横向误差 / 剩余距离`
4. **调到位精度**：车心距车位中心 ≤0.25 m、航向差 ≤3°、最后 P 挡保持 3 s
