## 二、完全没做的场景

### 1. 异形车道泊车（车位轴线 21.3°）

| 项 | 内容 |
|---|---|
| 几何 | 车位中心 (−8.48, −2.04)，ori 21.3°，需净转 **111.3°**；弦长 8.70 m、横向仅 2.1 m |
| 为什么难 | 单圆弧 + 直倒横向余量不够，必须**三点掉头**（前进—倒车—前进） |
| 已做 | `tools/park_angled.py`：几何解已验算（37.1°/37.1°/37.1°，每段弧长 3.41 m） |
| 下一步 | 先 `--dry-run` 看规划，再实跑；重点是**旁边有停放车辆**，可行域比几何解更紧 |
| 风险 | 三段满舵掉头，每次换挡都有速度突变 → 必须在换挡前**完全停稳**，否则加速度爆表 |

### 2. 斜坡泊车（平行车位 + 15° 坡）

| 项 | 内容 |
|---|---|
| 几何 | 车位中心 (−10.09, −2.84)，ori 90°（平行车位），地面 15° 坡 |
| 为什么难 | 平行泊车本身要两个圆弧（Reeds-Shepp 型），叠加坡度后**纵向加速度含重力分量**，|a| 更难压 |
| 建议方案 | ① 先在平地验平行泊车（`control/parallel_parking.py` 已 210 ×5）② 再加坡度补偿：上坡时目标速度降 20%，刹车力度按 `g·sin15°≈2.5 m/s²` 预留 |
| 未做 | 没有写专门的斜坡版本；`parallel_parking.py` 是否自带坡度补偿未确认 |

## 三、验证顺序建议

1. **车辆跟随**（最简单，纯纵向）
2. **车辆紧急停止**（分段刹车先写好）

4. **异形泊车**（几何已备，需实跑调）
