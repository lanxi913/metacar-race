## 一、设计：每个数值都能溯源

| 量 | 来源 | 实现 |
|---|---|---|
| 横向/纵向加速度上限 | **规则** | `A_LAT_MAX = A_LONG_MAX = 5.0 m/s²`（赛事要求 `|a| ≤ 5`） |
| 速度上限 | **规则** | `V_RULE = 60 km/h = 16.67 m/s` |
| 轴距 `L` | **车辆（在线标定）** | `L = v·tan(δ)/ω`，用实测横摆角速度反算，滑动平均 |
| 舵角→曲率 `k` | **车辆（在线标定）** | `k = ω/(v·δ)`，滑动平均 |
| 路径曲率 `κ(s)` | **场景数据** | `static.route` 折线三点外接圆，带符号（左转正） |
| 过弯限速 | **物理** | `v = √(A_LAT_MAX / κ_ahead)` |
| 横向控制 | **物理** | Stanley：`δ = atan(L·κ_ff) + ψ_e − atan(e/v)`，**增益 1，无量纲** |
| 纵向控制 | **无量纲** | 油门 = `(v_cmd−v)/v_cmd`，刹车 = `(v−v_cmd)/(v_cmd+1)` |
| 前视时间 | **车辆（实测）** | 用最近帧"油门→速度"滞后均值，初始 0.3 s |

只有一个"接口常量"：`STEER_FULL_SCALE = 0.6 rad`（`VehicleControl.steering ∈ [-1,1]`
对应的前轮转角满量程），属于车控协议定义，不是调参。

## 二、实跑结果（连续场景 1）

子场景：`直角转弯 / 车辆变道 / 车辆直行 / 连续转弯 / 垂直泊车`
路线：**1341 点、1339.6 m**

| 指标 | 实测 |
|---|---|
| 跑通距离 | **1338.2 / 1339.6 m**（前 4 个元素全部通过） |
| 横向误差 | 直线段 `|e| ≈ 0.01~0.05 m`，弯道最大 `≈ 1.1 m`（出现后 1 s 内收敛） |
| 速度自适应 | 直线 **13.3 m/s**（48 km/h），急弯自动降到 **4.7 m/s**（17 km/h） |
| 在线标定 | 轴距收敛到 **2.6~3.6 m**，随载荷/坡度小幅变化 |
