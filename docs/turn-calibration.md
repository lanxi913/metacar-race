# 直角转弯标定记录

日期：2026-10-23
场景：`直角转弯`
目标：100 秒内到达终点，避免压线，并获得加速度加分。

## 实测参数

| 参数 | 值 | 说明 |
|---|---:|---|
| 油门 | `0.01` | 与车辆停止题相同的安全纵向响应 |
| 前视距离 | `3.0 m` | 匹配题目的 3 m 曲率，避免大前视切弯 |
| 终点处理 | 不主动停车 | 持续向前，交给平台判断到达 |

## 关键结论

- 车辆停止题的前视距离是 6 m，直接用于直角转弯会切弯并造成轻微压线。
- 将前视距离缩短到 3 m 后，车辆可以沿 3 m 曲率路线转弯。
- 到终点前主动驻车会使平台无法触发完成判定；直角转弯应继续保持前进。
- 油门保持 `0.01`，实测加速度加分仍然有效。

## 复现

先启动脚本，再在客户端启动“直角转弯”场景：

```powershell
.venv\Scripts\python.exe -u tools\run_track.py `
  --throttle 0.01 --lookahead 3 --max-seconds 100
```
