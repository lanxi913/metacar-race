# VLA 停车区任务（子任务一）——三层走通设计文档

> 子任务：**在禁停区（40×40 m）里贴着内侧边缘稳稳绕一圈，不出界、不撞车。**
> 代码：`vla_stack.py`（三层本体）、`vla_stack_sim.py`（离线验收台，不连仿真）。
> 本文只讲**逻辑链 → 决策层 → 算法层**这三条路怎么排、怎么接、怎么验；不写时间轴、不背答案。

---

## 0. 三条路的分工（一句话版）

| 层 | 回答的问题 | 产物 | 失败时的降级 |
|---|---|---|---|
| ① 逻辑链 Chain | **顺序**：先看什么、后算什么 | 一帧一步的固定管线 | 某步给不出量 → 用上一帧值 + 记 `degraded` |
| ② 决策层 Arbiter | **取舍**：安全/贴合/节奏谁说了算 | 唯一一组 `(v_t, steer, thr, brk)` + 决策理由 | 冲突时按优先级否决，永不输出"两项都要" |
| ③ 算法层 Algorithm | **怎么算**：几何、曲率、滤波 | 参考线、横向偏差、限速、舵角 | 曲率/视觉异常 → 退回纯几何直线段 |

三层之间只有**数据**流动，没有互相调用：逻辑链调决策层，决策层调算法层，算法层是纯函数（给数出数）。
所以同一份决策与算法，**可以喂真车，也可以喂离线运动学模型** —— 这就是"走通"的口径。

---

## 1. 逻辑链（Chain）：固定六步，每帧一次

```
perceive → locate → plan → decide → actuate → log
```

| 步 | 输入 | 输出 | 说明 / 失败降级 |
|---|---|---|---|
| perceive | cam0 图像 | `Corridor(occ, gap_bins, free_deg)` | 无图 → `occ=0, gap=64`（等价"看不见但当成畅通"，但速度上限维持 2.5，不会盲冲） |
| locate | `pos_x/pos_y/ori_z/speed` | 投影点 `i`、`e_lat`、`s_along` | 投影失败（距离 > 5 m）→ 用上一帧 `i` 继续，记 `lost_track` |
| plan | `regions` 矩形 | 圆角参考线 `RefPath` | 无 `RESTRICTED_PARKING` → 用 `FUNCTION_ZONE`；都没有 → 拒绝起步并报错 |
| decide | `e_lat/e_head/κ/Corridor` | `Decision(v_t, steer, thr, brk, mode)` | 见第 2 节 |
| actuate | `Decision` | `VehicleControl` | 一律 `GearMode.DRIVE`，**永不下发 REVERSE** |
| log | 全量 | `run.csv` 一行 | 每帧都记，事后可离线复核（含决策理由字符串） |

**为什么顺序不能换**：`locate` 必须在 `decide` 之前（没有横向偏差就没有贴合）；`perceive` 必须在 `decide` 之前（安全是否决项，必须后算才不会被你覆盖）。

## 2. 决策层（Arbiter）：优先级否决，不做时间表

### 2.1 三条规则的优先级

| 级别 | 规则 | 触发条件 | 动作 | 为什么在这个位置 |
|---|---|---|---|---|
| **L0 安全** | 走廊否决 | 最宽自由区间 `gap < 12 bin` | 舵角 = 0.55·贴合舵角 + 0.45·空档方向；`v ≤ 1.4` | 撞车 −100、越界是判罚项，必须能一票否决 |
| L0+ | 走廊急停级 | `gap < 7 bin` | `v ≤ 0.8` | 空档太窄：慢到能不撞地蹭过去，**不倒车**（用户死命令） |
| **L1 贴合** | 前馈 + 双反馈 | 每帧 | `steer = atan(L·κ)/δmax + K_h·e_head + K_c·e_lat` | 贴合靠闭环；前馈负责"提前打舵" |
| **L2 节奏** | 曲率限速 | 每帧 | `v ≤ min(2.5, √(a_lat·R))` | 速度是**被动量**，只被削减，永不主动要求加速超过上限 |

### 2.2 仲裁顺序（代码里就是执行顺序）

```
v_t   = min(2.5, V_CAP, sqrt(A_LAT / κ))      # L2 先算上限
steer = ff(κ) + K_h·e_head + K_c·e_lat        # L1 算主项
if gap < 12: steer = 0.55·steer + 0.45·空档;  v_t = min(v_t, 1.4)   # L0 否决
if gap <  7: v_t  = min(v_t, 0.8)                                   # L0+
steer = 低通(限斜率(steer))                    # 慢响应
thr/brk = 加速度空间(1.2·(v_t − v), 夹 ±1.6)   # 纵向
```

### 2.3 决策层的三条"不许"

1. **不许有时刻表**：没有任何 `if t < 3:`。所有分支的条件都是当场测出来的量（κ、e_lat、gap）。
2. **不许记忆地点**：不写"西南角减速"，只写"任意位置 gap<12 就减速"。换一辆车、挪 3 m、换起点，代码不改。
3. **不许倒车**：算法层根本没有到 GEAR_REVERSE 的通路（`grep -n REVERSE vla_stack.py` 应为 0 处）。

### 2.4 决策留痕

每帧记录 `mode ∈ {run, corner, avoid}` 与理由串，例如：

```
[curve:v_t=1.70(R=4.8)] [track:ff=+0.38 head=+0.02 lat=-0.01]
[corridor:gap=9 free=-18° v≤1.4]
```

事后一条命令就能查"这一帧为什么慢/为什么打舵"。

## 3. 算法层（Algorithm）

### 3.1 参考线：圆角矩形（把"提前转弯"变成几何事实）

```
内缩 e_ref = 1.85 m = 车宽/2(0.95) + 安全余量(0.90)
圆角 R     = 4.8 m  = 车最小转弯半径 4.6 × 1.04
圆弧起点   = 角点前 R·tan(22.5°) ≈ 2.0 m
```

- 四个角换成 4.8 m 圆弧 ⇒ 车到角前 2 m 就开始进弧，**不需要"看到角才转"**。
- 参考线是闭环折线（点距 0.5 m，约 256 点 / 周长 ≈128 m），可任意起点并入（投到哪从哪开始）。

### 3.2 定位：投影出横向偏差

```
对每条折线求最近点 → (i, 切向 t, 距离 d)
e_lat = (p − p_i) · n_left,   n_left = (−t_y, t_x)      # 车在路径左侧为正
e_head = wrap180(yaw_ref − yaw),  yaw_ref = deg(atan2(−t_y, t_x))
```

### 3.3 前馈曲率：三点圆，取前方 3~6 m

```
κ = 4·Area / (|ab|·|bc|·|ca|)     # a=p(i+3 m), b=p(i+4.5 m), c=p(i+6 m)
```

### 3.4 舵角：前馈 + 两个反馈

```
δ_ff  = atan(L_kb · κ)                 # 自行车模型的稳态转角
steer = δ_ff/δ_max + K_h·e_head + K_c·e_lat
K_h = 0.020 /deg        K_c = 0.12 /m
```

### 3.5 慢响应（用户要求"响应过程也放慢"）

```
|Δsteer| ≤ 0.015 /帧（30 Hz ≈ 0.45/s）
steer   = 0.7·steer_prev + 0.3·steer_new
thr     ≤ 0.35，且每帧增量 ≤ 0.05
brk     ≤ 0.06（只在对目标速度降速时轻点）
```

### 3.6 速度：只由曲率与走廊决定

```
R    = 1/κ（κ<1e-3 视为无穷大）
v_t  = min(2.5, √(0.6·R))    → 直道 2.5 m/s（9 km/h）、R=4.8 弯 ≈1.7 m/s
a_cmd= clamp(1.2·(v_t − v), ±1.6)       ← 远低于扣分线 5
```

### 3.7 走廊感知（L0 的唯一依据）

```
地平线以下 3~13 m 窄带 → 按列统计 V<105 的比例 → 64 段占用曲线
在中心 ±55° 内找最宽的低占用连续段 → (gap_bins, free_deg)
gap<12 才启用"朝空档偏 + 降速"，避免被误检带偏
```

## 4. 参数表（每个数字的来源）

| 参数 | 值 | 来源 |
|---|---|---|
| `WHEELBASE` | 2.6 m | 车（SDK `main_vehicle`） |
| `R_CORNER` | 4.8 m | 最小转弯半径 4.6（车）×1.04 |
| `E_REF` | 1.85 m | 车宽/2 0.95 + 安全余量 0.90（几何） |
| `V_STRAIGHT` | 2.5 m/s | 用户"慢点、20 以内"，且一圈 ≈55 s 留 30 s 给读号 |
| `A_LAT` | 0.6 m/s² | 1.7 m/s 过 R=4.8，横向加速度 0.6，方向盘不"抢" |
| `A_ACC` | 1.6 m/s² | 规则 |a|≤5 扣分，取 1/3 留余量 |
| `STEER_SLEW` | 0.015/帧 | 慢响应：0.45/s ≈ 26°/s |
| `STEER_LP` | 0.70 | 一阶低通时间常数 ≈0.1 s |
| `K_HEAD / K_CROSS` | 0.020/deg · 0.12/m | 手工整定：1 m 偏差 → 0.12 舵角 ≈7° |

## 5. 离线验收台（不连仿真）

用自行车模型喂**同一份** `Runner.tick()`，四个起点各跑一圈：

| 起点 | 目的 |
|---|---|
| (0,0) 朝东 | 最坏情况：从区外并入南边 |
| (2,2) 朝北 | 测"并入时的大角度转弯" |
| (30,40) 朝西 | 区内反向并入（顺时针方向） |
| (40,10) 朝南 | 贴着东边并入 |

**验收口径（五项全过才算走通）**

| 指标 | 阈值 |
|---|---|
| 出界帧 | 0 |
| \|e_lat\| max / 均值 | ≤ 0.6 m / ≤ 0.3 m |
| v max | ≤ 2.5 m/s |
| \|a\| max | ≤ 1.6 m/s² |
| 一圈 | 弧长 ≥ 周长（≈128 m） |

跑法（**要执行权限**）：

```
.venv\Scripts\python.exe <ws>\vla_stack_sim.py
```

## 6. 与上一版（vla_loop3）的差别

| 项 | loop3（卡死/出界） | vla_stack（本版） |
|---|---|---|
| 方向来源 | 只看"最近边"的切线，到角跳变 | 圆角参考线 + 前馈曲率 |
| 转弯时机 | 到角才转，甩出去 | 几何提前 2.0 m |
| 横向控制 | 无（只有航向） | `K_c·e_lat` 闭环贴合 |
| 视觉占用 | 直接混合舵角 | 只在 gap<12 时否决，避免误检带偏 |
| 响应 | 无滤波 | 斜率 + 低通 |
| 倒车 | 有（已删） | 无通路 |

## 7. 已知风险与兜底

| 风险 | 现象 | 兜底 |
|---|---|---|
| 西南角车多 | `gap<7` 长时间，速度掉到 0.8，一圈变慢 | 允许 `mode=avoid` 时把 `E_REF` 临时放大到 3.0（由 gap 触发，**不是时刻表**） |
| 网格暗格误检 | `occ` 偏高 | 占用阈值 0.12 + 只降速不换道；若整圈 `avoid` 比例 >30% 就抬高阈值 |
| 视觉丢线 | 无图 | 退化为纯几何跟踪（参考线本身就是几何），只影响 L0 |
| 起步打滑/蠕行 | 首帧 v 掉 | `v<0.4 且 v_t>0.8` 单帧 `thr=0.15`（咬合），不靠积分 |
