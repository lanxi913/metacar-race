## 五、绝对不能违反的技术红线

1. **加速度必须全程在 ±5 m/s² 内**，否则奖励分（+10）没了
   - 仿真右上角出现 `[加速度限制] 加速度高于/低于允许上限` 就是违规了
   - **不许踩急刹**，减速度超限同样扣分
   - 只用油门开关调速（0.10 / 0），换挡前滑行到 |v| < 0.08
2. 这个仿真车**任何非零油门都会蠕行到 4.76 m/s**（低挡位特性），别指望轻踩油门能慢
3. 坐标符号：`yaw = math.radians(-pose.ori_z)`，纯跟踪 `steer = -atan2(2·ly, d)/0.6`（已验证，别重推）
4. 车位障碍物 `type` 是字符串 `'PARKING_SLOT'`；障碍物字段是 `pos_x/pos_y/ori_z/len/wid`，**没有 center**
