# 车辆跟随首版记录

日期：2026-10-23

场景：`车辆跟随`

首版结果：**110 分，满分**

## 场景探针

- 主车初始位置约 `(-1.88, -2.07)`，航向 `90°`。
- 前车类型为 `CAR`，与主车同车道，起始中心距离约 `42.44 m`。
- 前车最高速度约 `7.65 m/s`，约 `15 s` 后在前方约 `100 m` 处停车。
- 场景时限 `60 s`，主车终点在前方约 `80 m`。
- 前车通过 `msg.obstacles` 和 `ObstacleType.CAR` 动态识别，没有写死 ID 或坐标。

## 首版控制

- 用车辆矩形沿主车航向的投影计算净车距。
- 根据前车速度、时间车头距和安全制动距离计算目标速度。
- 同时受最小安全净距和终点剩余距离约束。
- 油门、刹车分别限斜率，保持互斥，并用平滑加速度降低指令冲击。

首版验证轨迹：

- 主车平稳加速至约 `4.78 m/s`。
- 前车减速停车后，主车在约 `15.7 s` 开始收油和制动。
- 平台在约 `20 s` 完成任务并给出 110 分。

## 新规则：情境自适应参数

后续代码减少针对单一场景的固定参数，优先根据当前情境计算目标值：

- 由净车距和相对速度决定速度修正；
- 由前车速度和驾驶员反应时间决定期望车头距；
- 由安全减速度和剩余距离决定制动点；
- 由道路宽度、车道中心线和车辆尺寸决定横向安全范围。

控制逻辑保持不变。参数调整应只改变输入到控制量的映射，不改变已验证的状态机、
控制顺序、油门与刹车互斥关系和安全停车逻辑。

固定车辆物理参数和平台硬阈值可以保留，但必须注明单位、来源和适用条件。
