# 设计原则：现场因素优先，少写经验常数

> 适用范围：**本项目所有场景**（场景元素 / 连续场景 / VLA / 港口迷雾），
> 从 2026-10-23 起对新写的控制器一律生效。

---

## 1. 原则

**能从场景里读出来的，就不要写成常数。**

| 该读的现场因素 | 数据来源 | 不要写成 |
|---|---|---|
| 限速值 | `SPEED_LIMIT_SIGN` 障碍物的 `extra_info`（如 `SpeedLimit\|20`） | `LIMIT = 20` |
| 车位位置/尺寸/朝向 | `ObstacleType.PARKING_SLOT` 障碍物 | 写死坐标 |
| 障碍物（前车、路障、行人） | `SimMsg.obstacles` 实时列表 | 写死位置 |
| 路线、车道、停止线、路侧边线 | `SceneStaticData.route / roads / lanes` | 写死路径点 |
| 时间限制 | `SceneStatus.time_limit` | 写死 100 / 200 s |
| 车辆自身尺寸 | `MainVehicleInfo.length / width` | 写死 4.8 × 2.2 |
| 车辆动力特性（平台速度、加速能力） | **在线自标定**：缓慢加油门并测速，检测到平台就锁住 | 写死"油门 0.45 得 17.2 km/h" |

允许保留的常数只有两类：

1. **物理/车辆模型的固定量**（轴距、最大前轮转角）——它们是平台参数，不是经验值；
2. **工程裕量系数**（例如"目标速度取限速的 92%"）——这类要写明理由，且必须是
   **相对量**（占限速/占车位宽度的比例），不能是"17.2 km/h"这种绝对经验值。

---

## 2. 反面教材（本项目真实踩过）

| 经验写法 | 问题 | 现场写法 |
|---|---|---|
| `THROTTLE = 0.45` | 换一辆车/一次改版就失效 | 在线标定：油门爬到车速不再上升，锁住该值 |
| `V_TARGET = 4.78` | 这是某次实测的平台速度 | `v_target = 限速 × 0.92` |
| `SLOT = (-9.78, -2.84)` | 训练题专用，正式赛是泛化版 | 读 `PARKING_SLOT` |
| `phi = 56°` | 只对这套车位尺寸成立 | 由 `d = x_slot - lane_x` 与转弯半径在线求出 |

## 3. 落地方式

- 控制器构造时，先把场景里能读的东西一次性读完，打印出来（便于复盘）
- 需要标定的量（平台速度、转弯半径）在**运动开始后的前几秒**自标定，锁存后不再变
- 日志里必须能看出"这个参数是读来的还是标定来的"，例如：
  ```
  现场读取: 限速 20 km/h @ (-8.2, -46.6)
  == 自标定完成: 油门 0.781 -> 平台速度 17.23 km/h ==
  ```

---

## 4. 一个反直觉的实测结论

**在线自标定不等于在线闭环。**

`车辆直行` 与 `限速行驶` 两题实测：

- 恒定油门（标定后锁死、全程不刹车）→ **110 分**（含 `|a| ≤ 5` 的 10 分）
- 闭环补油门 / 点刹维持速度 → **100 分**（加速度抖动丢掉加分）

所以正确姿势是：**用现场手段标定出合适的开环量，然后开环执行**，而不是用一个
闭环去追一个写死的目标值。
