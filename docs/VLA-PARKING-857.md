## 四、识别层结构（`tools/vla_score_run_857.py`）

- 控制线程 + `--dup` 个 OCR 子进程（每路相机 1~2 个），中间只有一格覆盖槽 + 共享内存 + 结果队列；
  **控制线程从不做 OCR / 编码，识别线程从不发指令**（运动层与识别层完全隔离）。
- 车框：YOLO（`best.pt`，conf 0.15 / iou 0.60 / imgsz 512，自定义 2 类 car+plate）；`--yolo 0` 退回彩色分割框。
- 读号：RapidOCR（PP-OCRv4，`intra_op_num_threads=1`）**整帧直读**，不裁 ROI（裁了反而慢 2~4 倍）。
- 归一化：`D/O→0`、`8→6`，只接受 `B-01~B-06`；编号在**车门侧面白字**（车顶蓝牌只有 12~16 px，不可读）。
- 交卷：`laps_done >= laps or now > seconds`，过滤 `票数 ≥ min-votes 且 最高分 ≥ min-score`，
  按「票数↓、最高分↓」取 `--top-n 4`，`VLAExtensionOutput(parking_result=...)` 只交一次。

## 五、被实验否掉的做法（不要再加回来）

| 做法 | 结果 |
| --- | --- |
| 内环扫掠（inset 12 m 穿车阵补票） | 60 s 撞车、卡死 46 s，平台 707.14 |
| 出弯加深 0.2 m（bump） | 用户否决（「歪主意」），且只堆出 1~2 票 |
| 1.5 m 死区弱回打 / 直道零航向 | 离线稳态偏差翻倍，真车直接冲出禁停区 |
| 第一圈记忆表辅助第二圈 | 用户否决（「换一个思路」） |
| 裁框 OCR / `use_det=False` | 只识别 → 垃圾输出；裁框带检测 → 慢 2~4 倍且无增益 |
| 弯里减速读号（`--read-speed`） | NW 角犁出参考线、未交卷 |
| 8 m 内整体减速 | 会让两圈超过 120 s 时限 |

## 六、还差什么（要冲 1000 的话）

1. **第 4 辆车的票数**：目前只有 1 票、且单票易错。可行方向是「同一编号跨帧多读几帧」——
   例如读到 1 票后让车在该段整体降速（不能分段降速，否则 120 s 不够），或增加 `--dup` 到 2（今天已试，4 号最多也只是 2 票）。
2. **罚分**：少数趟次会撞车（−100）或出现 `|a|>5`（−50）。850 那一趟就是「4 个全对 + 150 罚分」，
   把罚分清掉就是 1000。
