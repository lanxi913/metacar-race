# 平行车道泊车标定记录（210 分，连续 5 次）

日期：2026-10-23
场景：`平行车道泊车`（场景元素第 22 题，总分 200 + 加速度 10 = 210）
实现：`metacar_race/control/parallel_parking.py`，参数在 `metacar_race/config.py` 的 `PARALLEL_*`

## 一、场景几何（实测，脚本自己从 obstacles 读，不写死）

| 对象 | 坐标 | 说明 |
|---|---|---|
| 自车起点 | (-6.35, 30.00) yaw=90 | 沿 -Y 驶来 |
| 车位 | (-9.78, -2.84) ori_z=90 | 5.5 × 2.5，与车道平行 |
| 两侧车 | (-9.78, +3.79) / (-9.78, -8.97) | 各 4.0 × 1.7~1.8 |

横向距离 **L = 3.43 m**；满舵半径 **R = 5.38 m**（由轴距 2.6 / tan(0.6×0.75) 算）；
入位角 **θ = acos(1 − L/2R) = 47°**。

## 二、为什么是两段圆弧

侧方停车的横向位移只能靠"倒车圆弧 + 反舵回正"两段弧完成，
两段等半径圆弧的总横移量正好是 `2R(1−cosθ)`。反解得到

```
cosθ = 1 − L / (2R)
```

本场景 L=3.43、R=5.38 → θ=47°，实测甩到 42.9° 时车身已进入车位前缘，反舵回正后
横向偏差只剩 0.33 m，由 FIT 阶段微调吃掉。

## 三、四个必须踩准的点

### 1. staging 必须与"远端那辆车"并排

平行泊车要先开过车位、停在与**车位远端那辆车**并排的位置，再倒进来。
早期版本按"车位中心 + 偏移"算 staging，结果车停在车位另一侧，倒车方向完全反了。

现在直接取障碍物里那辆 `CAR` 的中心 + 0.15 m 余量，换场景也不会错。

### 2. 舵角要斜坡、不能满舵

满舵（1.0）+ 静止起步会让车轮顶住静摩擦，实测车直接 **v=0 卡死 30 s**。
改成：舵角从 0 在 1.2 s 内斜坡到 0.75，且低于 0.3 m/s 时先给连续油门破静摩擦。

### 3. 收尾不能纯滑行

纯滑行（throttle=0、brake=0）会让车多滚 1 m 以上，把 dy 从 0.3 带到 −1.08，
车身探出车位。改成 `brake 0.06` 轻刹收速，dy 稳定在 0.34 m。

### 4. 加速度分（那 10 分）靠三处细节

| 位置 | 现象 | 对策 |
|---|---|---|
| 起步 | 连续 0.01 油门在挂挡瞬间窜到 **6.8 m/s²** | 油门改 PWM 占空比，**上限 0.5**，0.0006/帧斜坡 |
| 倒车 | 满舵静止起步卡死 | 舵角斜坡 + 破静摩擦油门 |
| 收尾 | `brake 0.10` 在 0.2 m/s 时一帧打停（**8.3 m/s²**） | 先轻刹到 0.06 m/s 再进保持 |

改完 max\|a\| 从 8.33 降到 ≈5.0，平台开始给 210。
