## 二、控制器与关键参数

### 1. 循迹类：`tools\track_bonus.py`

| 参数 | 含义 | 推荐值 |
|---|---|---|
| `--cruise` | 巡航速度 m/s | 4.0（长路线 5.5） |
| `--offset` | 参考路径横向偏置 m | 0.8~1.3（看是否压线） |
| `--cscale` | 弯道限速倍率 | 1.0（长路线 2.0） |
| `--nobrake` | 超速只滑行不刹车 | 压线场景建议开 |

### 2. 泊车：`tools\park_v8.py`

基于车位坐标系推导，无场景魔法数：

```
对位点 = 车位中心 + R·u − side·R·v
倒车 90° 圆弧 → 车头对齐 → 直线倒进车位
```

### 3. 车辆停止：`tools\stop_run.py`

速度曲线 `v_t = sqrt(2·0.7·(d−0.03))`，停稳判据 3 cm。

## 三、加速度合规经验（重要）

| 结论 | 证据 |
|---|---|
| 仿真车任何非零油门都蠕行到 4.76 m/s（低挡位） | 油门 0.02 时速度仍是 4.76 |
| 刹车会触发「加速度低于允许下限」 | 连续转弯用刹车时违规 4 次，改 `--nobrake` 后 1 次 |
| 起步要软（前 3 秒油门限制 + 轻刹斜坡） | 直角转弯 110 的配置 |
| 横向运动也计入加速度 | 弯道压线时同时报「加速度高于上限」 |
| 奖励分 = 全程无违规 | 有 1 次违规即从 110 降到 100 |

## 四、复现方式

```bat
:: 循迹类（举例：u 型弯）
.venv\Scripts\python.exe -u tools\track_bonus.py --offset 0.8
:: 然后点客户端「启动场景」

:: 泊车
.venv\Scripts\python.exe -u tools\park_v8.py

:: 自动跑分（含降温与清窗口）
powershell -File tools\night_run.ps1 -RunTimeoutSec 200 -CooldownMinutes 90 -CooldownSleepMin 15
```
