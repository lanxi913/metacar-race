## 三、奖励分（+10）怎么拿

**判定口径**：仿真在右上角实时打「[加速度限制] 加速度高于/低于允许上限」，**只要出现一次，110 变 100**。
自测的「1 秒窗口差分」不可靠，必须以仿真提示为准。

四条已验证的经验：

1. **车辆任何非零油门都会蠕行到 4.76 m/s**（低挡位），想慢只能靠别的手段
2. **刹车会触发「加速度低于下限」** → 循迹类用 `--nobrake`（超速只滑行不刹车）
3. **横向运动也算**：弯道压线时同时报加速度超限
4. **起步要软**：油门斜率 0.0015/帧 + 前 3 秒限幅

连续场景1 的实测补充（逐帧数据见 `docs/09-continuous-scene-parking-accel.md`）：

5. **起步瞬态不可控**：油门压到下限 0.02~0.04，平台起步仍会甩出 12~34 m/s²
   → 「直角转弯」那 10 分注定丢，别为它折腾控制参数
6. **倒挡阶跃同样吃亏**：油门 0.04→0.16 的跳变报 −16 m/s²；但**倒车速度剖面就是泊车几何**，
   把输出限幅（刹车封 0.10、油门封 0.10）会让入库横向落点从 −0.089 m 变 −0.226 m，泊车直接 0 分。
   试过，已整体回滚（`83c7a29`）
7. 630 = 600 基础 + 变道 / 直行 / 连续转弯 各 +10；丢分的就是第 5、6 条那两个元素

`tools/track_bonus.py` 现成参数：

```
--offset  参考路径横向偏置（米，正=向左），压线就调大：u型弯 0.8、连续转弯 1.3
--cscale  弯道限速倍率（默认 1.0，长路线赶时间用 2.0）
--nobrake 超速只滑行不刹车
--cruise  巡航速度（默认 4.0，长路线 5.5）
```

## 六、已知坑（排错先看这里）

| 现象 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: metacar` | 用了系统 python | 用 `.venv\Scripts\python.exe` |
| 一直「等待算法连接」 | 上次脚本没退、占着 5061 | 杀掉所有 python 控制器进程 |
| 「场景文件不存在」 | 场景包多一层目录 | `python -u tools\fix_scene_dirs.py` |
| 点「启动场景」启动错场景 | 列表滚动位置变了 | 先把列表滚回顶部再点 |
| PowerShell 脚本中文乱码 | 文件丢 BOM | 保存为 UTF-8 with BOM |
| 分数 100 而不是 110 | 有 1 次加速度违规 | 见第三节，调 `--nobrake` / `--offset` |
| 连续场景泊车 0 分（明细里没这一行） | 车身越出车位边框（`slot_margin < -0.16 m`）或没到停车检查点 | 看 `logs/park_cs/*/park_cs.csv` 的 `slot_margin` / `slot_dist`；−0.03 以内才稳 |

六个用实测换来的结论：

1. **舵机符号是反的**：`steer=+0.6` 让航向从 180.0 变 165.5（−14.5°），即 **+1 是右舵**。
   文档里旧记的「+1 左」是错的，控制器输出必须乘 `STEER_SIGN=-1`。就是这条把 Car_C 送进
   `CustomsInspectionWarehouse` 卡死（`[collision]` 刷屏、之后油门踩到 0.62 也不动）。
2. **航向可以直接读 `orientation.z`**：车头朝西时 `ori_z=179.9998`，和位移法一致，
   **不用再加 180°**（旧标定的 `rotation_y+180` 是同一个数，但方向理解错了）。
3. **这个场景没有任何图像接口**：`get_image / get_camera / get_frame / screenshot / get_lidar`
   等 19 个命令一律回 `not available in student API mode`；`get_vehicle_state` 里也只有
   位姿/速度/控制量。回包 schema 里有个 `screenshot_path` 字段但始终为空。
4. **车走不动就立刻倒车**（用户 23:07 定的规矩）：往前踢油门只会越顶越死——实测 Car_A 在
   (734.1,−34.1) 连续踢 300 s 油门一米没动，把整局耗光。改成 1.2 s 不动就 `REVERSE` 退 1.1~2.3 m，
   **倒车后必须 `reset_pose` + `drv.reset_heading()`**（倒车位移方向反 180°，不清会把航向带反）。
   实测那次倒车 9.35 m 之后重新进闸，`request_entry` 直接获批。
5. **路口 release 的正确点位是 (729.0,−9.9)**：北向穿闸时，y 在 −30~−15 报
   `has not physically cleared the intersection`，到 −10 才 `granted=True`。所以沿 x=728.79
   一路开到 y≈−10 再 release，别在中途试。
6. **通行完必须把车开走**：Car_A 停在出口正北，Car_B 出闸时两车实体碰撞（`[collision] Car_A 与 Car_B`
   刷了 40 多条）。现在成功后自动开到 (734,44) 让路。

`fog_safety` 的门限不能按空旷场地定：中央闸口只有 5.06 m 宽，车摆在正中间时两侧净空就是 **1.10 m**，
门限高于它会让车在闸口里被刹住（22:53 实测卡在 (728.6,−26.5) 磨了十几秒）。

**下一步**：① 泊位 lv3（2×200）：两车必须在 30 s 内、间距 ≥5.3 m 各报一次，且都要在 ~13 m 内、车头朝向泊位；
② 加速度违规（`[excessive_acceleration]`）还在偶发，踢油门/弧线扫描的斜坡要再压；
③ 信号 B 的耗时（188 s vs 队友 142 s）还能靠分段限速再压。
