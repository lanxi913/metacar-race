# VLA 停车区任务（子任务二）——读号与交卷的三层设计

> 子任务：**把禁停区里违规车的编号读出来，一次提交，不误报、不撞车。**
> 规格与子任务一（`VLA-三层走通设计.md`）完全同构：逻辑链 → 决策层 → 算法层。
> 代码骨架：`vla_read.py`（不连仿真，等执行权限再跑）。

---

## 0. 目标函数（先把尺子立起来）

平台给分：

```
成功率 = 2A / (A + B)          A = 报对的数量   B = 报错的数量（错的 + 漏的算在一起看公式）
得分   = 成功率 × 1000
A=0 且 B=0 → 1（不报也不扣）     单边为 0 → 0
```

**推论（决定了整个策略）**：

1. **多报比少报危险**：报错一个，`A+1` 的分母里多一个错项，且拉低 `2A/(A+B)`。
   只有 `p_violation > 0.5` 的车才值得去读、去报。
2. **读不到就不报**：读不到号的车等于"没看见"，不产生 B（但也没贡献 A）。
3. **时间就是分数线**：100 s 内跑完，超时判 0 ⇒ 任何"再确认一次"都要先算时间账。

## 1. 逻辑链（Chain）：七步，每帧一次

```
perceive → associate → assess → select → approach → read → vote → submit
```

| 步 | 输入 | 输出 | 失败降级 |
|---|---|---|---|
| perceive | cam0 图 | `[CarBox]`（色彩掩膜 + 形状过滤，已验证：3 辆车面积 3320/2134/980 px 全命中） | 无图 → 这一帧不产新观测 |
| associate | `CarBox` + 位姿 | 世界坐标车簇 `CarObs(x, y, ori, best_px, hits)` | 反投影失败（地平线异常）→ 丢弃该框 |
| assess | `CarObs` + `regions` | `p_violation ∈ [0,1]` | 无区域信息 → `p_v = 0.5`（不报也不排除） |
| select | 候选 + 已读状态 + 剩余时间 | 下一个动作（是否去读、读哪辆） | 预算不够 → 直接进 submit |
| approach | 目标车 + 自身位姿 | 侧向掠过点 `(x, y)`（**不是朝车走**） | 目标过近（<3.5 m）→ 放弃本次，交给下一圈 |
| read | 目标 ROI | `(label, score)`，如 `("B-03", 0.87)` | 分数 <0.60 或形态不合法 → 记为 `None` |
| vote | 多次读数 | 该车最终 id（≥2 次一致，或 1 次 ≥0.85） | 冲突 → 取最高分；仍冲突 → 不报 |
| submit | 违规清单 | `VLAExtensionOutput(ParkingResult(violating_sticker_ids=[...]))` | 一旦提交即结束，**只提交一次** |

## 2. 决策层（Arbiter）：收益/代价比，不是流水账

### 2.1 读不读：`prize / cost`

```
prize(car) = p_read(d) × (2·p_violation − 1)      # 违规似然为 50% 以下时 prize ≤ 0 ⇒ 不值得读
p_read(d)  = 1 / (1 + exp((d − d50) / k))         # d50、k 由现场样本在线拟合（f2 实测 d50≈7.8 m, k≈0.30）
cost(car)  = |绕行距离| / v_now + 读一次的时间（≈2.5 s，实测）
选 : argmax prize/cost  ，且 cost ≤ 剩余时间 − 交卷成本
```

`(2p−1)` 这一项是关键：它能**自动拒绝**"停在合法车位里的车"（p≈0.05 → prize<0），
不需要写"哪些车不用读"这种记忆式规则。

### 2.2 怎么读：侧向掠过（不怼脸）

```
目标点 = 车心 + n_left(行驶方向) × d_ref     d_ref = 6.5 m（p_read 峰值附近）
航向   = 与"车心→我"的视线**垂直**（横向 90° 掠过）
终止   = 侧向掠过 4~6 m 后仍未读成 → 放弃（不回头、不倒车）
```

为什么不是"朝车开"：朝车开时最后 3 m 视角全是车头/车尾（**贴脸读不到**，p1 实测 `wmax=274 px` 仍读空），
而 45°~135° 的侧面才是贴纸可见区（`B-03` 在 7 m 侧向读出 0.87）。

### 2.3 何时交卷：三条触发器，取最先发生

| 触发 | 条件 | 理由 |
|---|---|---|
| 信息饱和 | 所有 `p_v>0.5` 的候选都已定案 | 再跑也不加分 |
| 预算耗尽 | `剩余时间 < 交卷成本 + 安全停车时间` | 超时判 0，宁早不晚 |
| 强制兜底 | `t > 0.90 × 时限` | 最后一道闸 |

**只提交一次**：停车区任务提交即评分并结束子场景（官方文档明写），所以清单在提交前必须已经定稿。

## 3. 算法层（Algorithm）

### 3.1 车辆检测（已验证）

```
地面区（地平线以下）→ 车漆掩膜（H 分区 + S>60 + V>60）→ 形态学闭运算
→ 连通域过滤：面积 ≥380 px、填充率 ≥0.40、0.25 ≤ h/w ≤ 4.0、拒绝 y+h > 0.94H
```

### 3.2 反投影到世界（不需要标定板）

```
地面点距离 d ≈ K / (y_img − y_horizon)      # K = 2·f·H_cam，用两个已知点解出
横向   = d · tan(fov_h/2) · (2·u/W − 1)
```

`K` 用"B-03 那辆车实测 7 m 处底边 y=300、地平线 175"这类现场样本拟一次即可，写进日志备查。

### 3.3 违规似然 `p_violation`

```
overlap_in  = 车矩形 ∩ 禁停区面积 / 车矩形面积          # 核心判据
edge_out    = 车矩形超出合法车位带的最大距离            # 越界判据
p_v = clamp(0.5 + 0.5·(overlap_in − 0.15)/0.55, 0.02, 0.98)       # 占进禁停区就升
p_v = max(p_v, 0.55 if edge_out > 0.15 else 0)                    # 压线也算
```

（阈值 0.15/0.55 是"车身压进禁停区多少算违规"的几何余量，换成比例而非米，便于跨车尺寸泛化。）

### 3.4 读号（已验证的流水线）

```
白掩膜（V>175 且 S<55）→ 连通域形状过滤（h 7~70, w 1~60, 填充≥0.10）
→ 同行聚类（中心 y 差 <0.45h、x 相邻 <0.9h）→ 按高度归一化
→ 位置感知模板匹配（字母位只比字母、数字位只比数字）→ "^[A-Z]-\\d\\d$" 才认
```

### 3.5 投票

```
同一车：每次读数入桶；最终 id = 众数（要求 ≥2 次一致 或 单次 ≥0.85）
跨车：同一个 id 出现在两辆车上 → 都不报（几何归属冲突）
```

## 4. 与"一圈巡检"的衔接（时间账）

| 阶段 | 内容 | 预计耗时 |
|---|---|---|
| 贴边一圈 | 128 m / 2.5 m/s（弯道 1.7） | 55~62 s |
| 读号补拍 | 3~6 辆 × 6.5 m 侧向掠过（≈2.5 s/辆 + 绕行） | 20~30 s |
| 交卷 | 停车 + 提交 | 3 s |
| **合计** | | **78~95 s < 100 s** |

若中途"信息饱和"（一圈里已经读全），省掉补拍 ⇒ 70 s 左右交卷。

## 5. 验收口径（离线可算的部分）

| 项 | 判据 |
|---|---|
| 检测召回 | 离线已有帧里可见车逐帧命中率 ≥0.9 |
| 反投影精度 | 用已知车心 (25.85,0) 对拍，误差 ≤1.5 m |
| 读号准确率 | 存图里人工标注的号，OCR ≥0.8 命中 |
| 决策合理性 | 拖三组反事实：挪车 3 m / 删一辆车 / 改时限 60 s，看动作是否跟着变 |
| 交卷 | dry-run 输出清单与人工核对一致 |

## 6. 风险与兜底

| 风险 | 兜底 |
|---|---|
| `p_read` 拟合只基于 2 个样本 | 每读一次都 `add_read_sample`，在线更新 d50/k；日志打印 |
| 侧向掠过被别车挡路 | L0 走廊否决（同子任务一），只降速不换道、不倒车 |
| 反投影在坡道/遮挡时漂 | 只用于"选目标顺序"，不用于压线判定（压线仍用 SDK 区域几何） |
| 时间不够 | 三步触发器 + 硬底线 0.90×时限，先保证有成绩 |
