## 4. 这一版成功的原因（后续版本别乱改）

1. **两段真并行**：A 泊位段 `Car_D + Car_A` 同时发车；B 泊位段 `Car_B + Car_A` 同时发车（`drive_multi` 一次下发四车控制）。两车观测天然落在同一 30 s 窗口内。
2. **过闸不绕行**：获准后沿自然车道（x≈730.9 → 728.8）直接北上，11 s 完成 release。
3. **过闸速度 2.5~2.7 m/s**。
4. **全程不倒车**：A 交付后直接前出，16 wp 去 B 泊位。

## 5. 后续版本（m99~m103）为什么退步

| 改动 | 后果 |
|---|---|
| 加“先归中线 x=728.79 再北上” | Car_B 从此永远 `has not reached a connected intersection exit`，一路北漂到 y=115 |
| 油门上限压到 0.30 / 降 v_cap | 获准速度降到 1.24 m/s，release 判据不满足 |
| 加 `back_out()` / `turn_around()` / 卡死踢油门 0.42 | 出现 −6.29 m/s 倒车与 4.11 m 车距（车体重叠 0.9 m）⇒ 超速 + 碰撞 |
