# 港口迷雾 600 分方案（信号 + 扫描 + 查验通行）

> 实测记录：2026-10-30，`logs/portfog_full_60.log`。
> 信号 3/3（240）+ 路障扫描（160）+ 查验通行 2/2（200）= **600 分**。
> 泊位仍是 0/2，原因见文末。

## 两个文件

| 文件 | 作用 |
|---|---|
| `tools/portfog_run3.py` | 基础层：路网建图、规划、逐点跟踪、事件监听、读码提交 |
| `tools/portfog_full.py` | 全流程：信号链 → 扫描 → 路口 → 泊位 |

## 关键实现（都是被实测逼出来的）

1. **多车 API 是客户端**：`ScenarioTaskAPI(port=9100)` 主动连场景，所以顺序是
   「先启动场景 → 再跑脚本」。
2. **`PoseGnss.ori_z` 是从 +x 顺时针的累积角度（度）**：
   `yaw = wrap(-radians(ori_z % 360))`；`steer` 正 = 顺时针。
3. **路网用 `LaneInfo.path_points` 折线建图**，交叉口断口用 25 m 端点互连补齐；
   `nearest_lane_point` 对每段车道线做**投影**（不是只比端点），否则信号 A 会返回
   12 m 外的端点，车就斜穿广场压人行道。
4. **信号读码**：7 m 内 `visible_objects[*].hint` 里 `现场铭牌 Key：KEY-XXX`，
   `submit_key {"key": ...}`。
5. **路障扫描**：三信号后 `object_type == "roadblock"`，进 10 m 内 `scan`。
6. **路口申请**：车道 `PORT_H_INSPECTION_*_E_0`（正南），进口点取路口 −10 m（满足
   “>6 m 且 ≤12 m”），停车后 `request_entry`；**同一位置多试几次**（判定有抖动），
   granted 后倒车 4 帧把车头摆向南，再沿车道穿到对侧 13 m 处 `release`。
7. **速度**：平滑速度环，巡航 5.0 m/s、弯道 2.5 m/s，超 5.4 m/s 硬刹；
   之前用“超阈值点刹”会让车一会儿行驶一会儿等待。

## 复现

```powershell
# 1) 启动场景（或客户端里点启动），等 9100 监听
# 2) 跑
.venv\Scripts\python.exe -u tools\portfog_full.py --seconds 540
```

## 已知限制

- **泊位 0/2**：泊位精确位置要共享定位到 lv3 才公开，lv3 需要“3 个信号全确认 +
  两辆不同车 30 秒内的有效观测”。目前没有产生有效观测，`dest` 一直是 fuzzy。
- **路口穿通道不算稳**：granted 之后车头角度偏大时（例如 −148°）会剐西侧围栏，
  需要倒车摆正；成功率大约一半。
- **时间紧**：600 s 内跑完信号 + 扫描 + 两车路口很吃紧，经常只够一辆车过路口。
- 车辆会短距离离开车道去贴近信号点（信号在路外 4~5 m），压线风险仍在。
