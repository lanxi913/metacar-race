# 车辆紧急停止验证记录

日期：2026-10-23

场景：`车辆紧急停止`

最终结果：**连续 3 次 110 分**

## 场景结构

- 场景起点约 `(-1.90, 5.00)`，终点约 `(-1.88, -65.00)`。
- 前方唯一车辆类型为 `CAR`，与主车同车道。
- 前车最终停在主车停车点前方约 `5.18 m`，中心几何净余量约 `0.59 m`。
- 前车、终点和路线方向全部来自场景 API，没有写死 ID 或坐标。

## 失败复盘

| 次数 | 得分 | 问题 |
|---:|---:|---|
| 1 | 88.95 | 套用跟车安全净距，提前停车 1.304 m，位置扣 11.05 |
| 2 | 82.45 | 制动过晚，越过终点 0.526 m，位置扣 3.27、碰撞扣 14.28 |
| 3 | 105.09 | 制动仍略晚，越过终点 0.584 m，碰撞扣 1.06 |

## 最终方案

1. 用路线终点和最后一段路线方向建立停车坐标系。
2. 用主车相对终点的 `along`、`lateral` 坐标判断停车位置。
3. 计算前车在终点处的几何净余量，保留一半作为制动超调缓冲。
4. 由当前速度、响应时间和保守规划减速度推导目标速度。
5. 进入制动区后不重新加速，达到停车点后挂 P 挡保持。

最终参数的来源：

- 规划减速度取平台加速度上限的 `40%`；
- 响应时间取 `0.50 s`；
- 最小净余量按主车长度比例推导；
- 停车前置量取终点处可用前车余量的一半。
