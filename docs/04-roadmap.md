# 10 天路线图

报名 10-25 截止，比赛 11-01。每天一个交付物，交付物没出来不进入下一天。

| 日期 | 主线 | 谁 | 交付物 |
|---|---|---|---|
| 10-22 周四 | 报名 + 环境 | A | 报名信息待交；`check_env.py` 通过；车辆直行跑通 |
| 10-23 周五 | 循迹闭环 | B | 直行题跑完全程（100 分） |
| 10-24 周六 | 元素题铺量 | B + E | 停止、跟随、直角转弯、U 型弯各 3 次成绩 |
| 10-25 周日 | **报名截止** + 连续场景 | A + B | 报名回执；连续场景 1 跑通 |
| 10-26 周一 | VLA + 四车连通 | C + D | VLA 一次有效成绩；四车状态能读 |
| 10-27 周二 | 港口迷雾 400 分 | D | 信号 240 + 扫描 160 |
| 10-28 周三 | 港口迷雾 600–800 | D | 至少一辆车完成路口或泊位 |
| 10-29 周四 | 联调 + 去硬编码 | 全员 | 无写死坐标/key，能连续跑满 600 s |
| 10-30 周五 | 泛化演练 | E | 换场景重跑、异常恢复 |
| 10-31 周六 | 彩排 | 全员 | 全模块走一遍 + 录屏 + 备份 |
| 11-01 周日 | 比赛 | 全员 | 成绩与复盘 |

## 分阶段目标分

| 阶段 | 目标 | 说明 |
|---|---|---|
| 第一档 | 城市道路元素题稳定拿分 | 到达终点即满分，先不追求零扣分 |
| 第二档 | 连续场景 1–2 关 | 不压线优先，时间分是次要的 |
| 第三档 | VLA 三类任务各一次有效成绩 | 文本导航先保 600 分完成分 |
| 第四档 | 港口迷雾 400 分 | 信号 + 扫描，不需要协同 |
| 第五档 | 港口迷雾 1000 | 路口 + 泊位，最后攻 |

---

## 验收标准（队内通用）

一个任务算「完成」必须满足：

1. 代码在 `main` 分支能跑；
2. 有成绩截图或日志（得分、扣分项、用时）；
3. 文档里写清怎么复现（命令 + 参数）；
4. 别人拉下来能跑通，不用问你。
