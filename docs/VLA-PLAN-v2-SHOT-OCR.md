# VLA 停车区违规检测（二）—— 规划书 v2：YOLO 截图 + 截图读号

> 定稿：2026-10-27 上午　分支 `feat/vla-parking`
> 本版按用户要求**简化视觉链路**：不单独训练/检测车牌，改为 **YOLO 只负责“找到车”→ 每辆车截一张图 → 在截图里找号码 → 统计数量与违规**。

---

## 0. 一句话决策

**YOLO 当“眼睛”（只做车检测与截图），读号在截图上做，判定用几何，交卷用一次性 F1 最优。**

这样做的好处：车牌/车身编号不再需要单独检测模型（那是上一版最容易崩的一环：
20 m 处字只有 4~6 px，检测器根本框不住），而是把“读号”退化成**在已经框准的车图里找白色字符**，
失败率与现场光照、距离解耦。

## 1. 任务约束（来自规则文档，不改）

| 项 | 值 |
|---|---|
| 成功率 | `2A/(A+B) × 1000`（A=报对、B=误报），`A=0&B=0→1`，`A=0&B>0` 或 `A>0&B=0→0` |
| 时限 | **100 s**（超时判未完成=0） |
| 限速 | 30 km/h（超速 −50） |
| 加速度 | `|a| > 5 m/s²` 扣 −50 |
| 碰撞 | −100（累计） |
| 提交 | 停车区任务**提交即定局**，只能交一次 |

## 2. 逻辑链（八步，每步都有“失败怎么办”）

```
①感知   YOLO 检车（best.pt, imgsz=384, conf≥0.35）
          └ 失败：本帧跳过，不影响全局（单帧失败无代价）

②定位   车框中心 + 单目反投影（地平线 + 已知焦距）→ 世界坐标
          └ 失败：用“到车前距离上界 20 m”兜底，只用于去重

③去重   同一辆车在多帧里出现 ⇒ 用世界坐标 2.5 m 内聚类为一个 CarObs
          └ 一个 CarObs 允许多次截图，票数累积

④截图   对每个 CarObs 保留“最大车框”的那一帧裁剪（pad 15%）
          └ 只在车框高 ≥ 40 px（约 8~10 m 内）时才截图，太远不浪费时间

⑤读号   在截图里：白字掩膜 → 连通域 → 同行聚类 → 模板匹配 → "B-05"
          └ 相似度 <0.60 或形态不符 ⇒ 丢弃（宁缺毋滥，避免 B 类误报）

⑥判定   几何：车中心落在禁停区（RESTRICTED_PARKING）内 → 违规
          └ 边界 0.5 m 内算“不确定”，按先验概率处理（见 §4）

⑦记账   vote[car] += 1；票数 ≥2 且一致才进候选清单

⑧交卷   巡检结束（或 t ≥ 85 s）一次性提交去重后的编号清单
```

**关键取舍**：读不到号的车**不报**（漏报只降低 A，误报同时抬高 B、还会拉低 A，两头亏）。
所以策略天然保守：**有把握才报**。

## 4. 决策层：每一刻都在算三件事

1. **要不要为这辆车减速/拐一下**：只有 `prize(车) > 0.25` 且 `绕行成本 < 2 s` 才值得
   - `prize = p_read(d) × (2·p_violation − 1)`；`p_read(d)=1/(1+exp((d−d50)/k))`，`d50≈7.8 m`
   - 违规先验 `p_violation`：在禁停区内 =0.85；在合法车位带 =0.05；边界带 =0.5
   - 注意 `(2p−1)`：`p<0.5` 的车读出来也**不该报**（报错车加 B），所以不给它们花时间
2. **什么时候交卷**：`t >= 85 s` 或“连续 15 m 没有新的可读车” ⇒ 立即交（避免超时 0 分）
3. **这一帧要不要截图**：`车框高 ≥ 40 px` 才截（等价距离 ≤ ~10 m），否则等更近

## 5. 时间预算（按实测 73.4 s 一圈）

| 阶段 | 预算 | 说明 |
|---|---|---|
| 进场 | 0~6 s | 起点在禁停区外，斜插到场内 |
| 一圈巡检 + 截图 | 6~70 s | 边跑边截，不额外停车 |
| 补拍（最多 3 辆） | +10 s | 只对票数不足但 `prize` 高的车 |
| 余量 | 10~15 s | 交卷前留够，**绝不踩 100 s 线** |

---

## 6. 验收口径（离线可判，先过这道再上真车）

| 判据 | 门槛 |
|---|---|
| 截图成功率 | 场内每辆“可见车”至少截到 1 张（≥80%） |
| 读号率 | 已截图的车里 ≥70% 能读出合法 `^[A-Z]-\d\d$` |
| 误读率 | 读出的号与该车后续多帧投票一致率 ≥90% |
| 去重 | 同一辆车只产生 1 个 CarObs（用世界坐标验证） |
| 不误报 | 合法车位带里的车（`p_v=0.05`）**不进**最终清单 |

## 7. 落地顺序（今天）

1. `vla2/shotread.py`：YOLO 检测 → 截图 → 裁剪内读号 → 投票（纯离线模块，可单测）
2. `tools/vla2_shot_selftest.py`：对既有巡检帧跑一遍，输出“截了几张 / 读出几个 / 读错几个”
3. `vla2/mission.py` 改造：把巡检（已跑通的 `stack.py`）与 `shotread` 合并，加交卷门
4. 离线通过后再真车跑一次（约 80 s），读平台分

---

## 8. 不做什么（明确的非目标）

- ❌ 不训练车牌检测模型（用户明确：不单独检测车牌，靠截图读）
- ❌ 不做 OCR 深度学习模型（模板匹配已能读 `B-03`/`B-05`，样本量不值得训）
- ❌ 不为读号停车（停车=加速度事件+费时，只在 `prize` 高的车上才补拍）
- ❌ 不报“不确定”的车（F1 里误报是双倍惩罚）
