# 绿灯禁行（场景元素 25）

十字路口直行通过，**绿灯时如果出口被堵就不能驶入**，否则按"路口阻塞"扣分。

| 项 | 值 |
| --- | --- |
| 基础分 | 200 |
| 加分 | 全程 `|a| <= 5 m/s²` → +10 |
| 限时 | 200 s |
| 平台最好 | **200.00**（位置 / 压线 / 违反信号 全部 0 扣分） |
| 单程耗时 | 27.8 s（含 15 s 配速等待） |

## 一、规则（`场景元素评分规则.docx` 表 25）

1. 200 s 内从起点开到终点；
2. 压线 −20；
3. 触碰对手车时，按触发瞬间速度扣 −5×v；
4. 违反交通信号时，按触发瞬间速度扣 −5×v；
5. **绿灯驶入路口造成路口阻塞 → −20×v**；
6. 红灯时车头距停止线 10 m 内进入检测区，必须停在距停止线 0~3 m，否则 −20。

## 三、控制律

* 横向：车身坐标系纯跟踪（`desired_yaw = yaw_ref + atan2(k·e_ct, max(v,0.8))`）；
* 纵向：加速度空间 PI（`KP=1.0 / KI=2.0 / A_ACC_MAX=3.0 / A_ACC_SLOW=1.8 /
  THR_PER_A=1/150 / BRK_PER_A=1/32`，油门封顶 0.40、刹车封顶 0.09）；
* **配速到检测区边界**（本场的关键动作）：
  现在还不能进路口（红灯 / 绿灯但出口堵）且车头离停止线还 >11 m 时，把速度算成
  "绿灯亮起时正好开到检测区边界"：
  `v_pace = (d_head - 10 - 1) / max(绿灯还差多少秒 - 0.4, 0.3)`，限幅 `[0.30, 4.75]`。
  于是全程**一次到底、不踩停**；
* 只有"已经进了检测区又转红"或"配速来不及时"才停车（车头距线 2.5 m，落在合法 0~3 m 内）；
* 起步（场景起步和中途再起步用同一个策略）：`LAUNCH_THR=0.15` 快咬合 + `A_ACC_SLOW` 限加速；
* 终点：沿终点方向越过 2 m 再刹停（P 挡 + 刹车）。

## 四、为什么拿不到 +10（实测记录）

平台 `|a| <= 5` 的 +10 **只在场景最开始的约 0.5 s 内豁免**（左转 210、十字路口 210、
上下坡驻车 210 都是靠这个）。本场必须等 10 s 红灯，于是中途一定要"再起步"，
而 DRIVE 从静止起步必定产生离合咬合冲击：

| 试法 | 咬合冲击 | 结果 |
| --- | --- | --- |
| 只给 0.012 的油，靠怠速蠕行拖起来 | 一帧 +0.26 m/s ≈ **8.6 m/s²** | 200.00 |
| 给 0.15 的油快咬合（和场景起步一样） | 一帧 +0.70 m/s ≈ **20.6 m/s²** | 200.00（起步那次算豁免） |
| 预载 0.12 刹车压冲击 | — | **车被憋在原地抖了 138 s 只挪 2.2 m**（低速驱动力本来就比刹车小） |
| 按上一帧加速度事后补刹车 | 仍是 8.5 | 车反复"窜-憋-窜"，把绿灯窗口耗光 |
| 抛物线刹车削 0.25~1.05 m/s 段 | 仍是 7.8 | 形成极限环，21 s 才以 1.03 m/s 压线（抢红灯） |
| **不停车，配速到检测区边界** | 中途仍会穿过 0.3~0.9 m/s 蠕行带（13~15 m/s²） | **200.00**，但全程没停过车、动作为一条连续曲线 |

几何上的死结：起点到停止线只有 17.27 m，要在 14.9 s 的绿灯亮起时到线，平均速度必须
≈1.1 m/s，而 0.3~1.5 m/s 正是离合蠕行带（自身 6~8 m/s²）。所以本场
「必须等红灯」与「+10 要求全程 |a|≤5」是冲突的，200.00 就是上限。

## 七、未覆盖项

* 出口连续堵死（不是本场这种"5 s 后集体开走"）的情况没有实测，只要 `blocked` 一直为真，
  逻辑上会一直配速到检测区边界后停住等，可能超时；
* 黄灯相位本场没有出现，代码按"红灯"处理；
* `RED_LEN=10.0` 是从本场相位实测（绿 10 s / 红 10 s）来的常量，换场景要重新读相位。
